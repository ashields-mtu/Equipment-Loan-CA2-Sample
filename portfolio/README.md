# Final Design Dossier Guidance

The dossier should explain and justify selected evidence rather than reproduce the entire repository.

Recommended structure:
1. Project overview and Product Goal
2. Scenario selection and agreed baseline
3. Product Backlog and selected use cases
4. Behavioural design
5. Responsibility assignment and GRASP decisions
6. Integrated design class model
7. Object interactions
8. Design structure and shared interfaces
9. Traceability
10. Design evaluation and limitations
11. Process, contribution and AI evidence

# CA2 Definition of Done

A selected use-case design is Done only when:
- detailed use case and Gherkin are agreed;
- SSD is complete and black-box;
- principal operation contracts are complete;
- CRC and important GRASP decisions are recorded;
- design sequence diagram is complete;
- integrated design class model supports the messages;
- traceability links are updated;
- editable sources render correctly;
- peer review is complete;
- board and contribution evidence are updated.
